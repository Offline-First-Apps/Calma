## T07 — Migrate copy modules to locale files

- [x] `3361a80`
- **Commit:** `refactor(i18n): migrate copy modules to locale json`
- **Depends on:** T03
- **Touches:** `packages/i18n/src/locales/en/*.json`, `apps/native/src/copy/*` (removed)
- **Done when:** every string from `systems/07-copy-and-tone.md` lives in its feature namespace with a semantic key; all interpolation is named; **no sentence is assembled from fragments**; and `apps/native/src/copy/` no longer exists.
- **Notes (session 7):**
  - `apps/native/src/copy/` was never created, so there was nothing to remove.
  - The doc's global key prefixes become namespaces: `breathe.phase.inhale` →
    `breathing:phase.inhale`, `panic.*` and `suds.*` → the `breathing`
    namespace, `window.*` → `worry:window.*`, `paywall.*` → `entitlement`.
  - `skip` and `continue` moved to `common`. Duplicating a button label per
    namespace is a translation smell.
  - `window.summary` was split into four keys — see the amendment in
    `systems/07-copy-and-tone.md`. ICU pluralises on `count` alone, so one
    string carrying three counts would have read "1 were within your control".
  - The three feeling faces stay in the component rather than the JSON, which
    lets the tone test forbid emoji absolutely instead of maintaining an
    exception list.
